# Library dependences. #

If you want to use odiem whith boundled jndi sun stack, you don't need other libraries.

## Apache stack ##

Add following libraries to your classpath:

  * lib/apache/`*`.jar

## Novel stack ##

Add following libraries to your classpath:

  * lib/novell/`*`.jar

## Unboundid stack ##

Add following libraries to your classpath:

  * lib/unboundid/`*`.jar

## Opends/Opendj stack ##

Add following libraries to your classpath:

  * lib/opends/`*`.jar

## Advanced featured ##

If you want to search on a bean marked as abstract you have to add to your classpath

  * lib/**javassist.jar**
  * lib/**scannotation-1.0.2.jar**
